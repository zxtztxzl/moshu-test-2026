# 墨枢 (Moshu) — 本地多模型写作助手（测试版）

> ⚠️ **测试版 · 仅供邀请测试** ｜ 源码暂不公开，本仓库仅用于分发测试用安装包。

## 这是什么
墨枢是一个跑在你自己电脑上的多模型写作 / 整理助手。三种模式：单脑（本地模型）、集群（多模型分工）、线上（调用线上大模型）。所有数据留在本地，不上传。

## 安装
1. 到本仓库 **Releases** 下载 `墨枢安装.exe`（约 1.4 GB，已内含 Ollama 引擎）。
2. 双击运行 → 阅读并**同意隐私协议** → 选择安放目录 → 勾选「创建桌面图标」→ 安装完成。
3. 安装目录里**不会出现任何 `.py` 源码文件**（墨枢自己的代码已冻结进 exe）。

## 模型
安装包**不含模型**。装完后，把你的 GGUF 模型文件（或 Ollama 拉取的模型）放进安装目录下的 `models/` 文件夹。
- 没有模型时，启动会引导你：在交互界面里敲 `/下载模型 qwen3:8b`
- 推荐量化模型（吃内存的是模型本身）：qwen3:8b（约 5 GB）、qwen2.5-coder:7b（约 4 GB 多）、gemma3:4b（约 3 GB）

## 使用
- **任意目录**打开终端，敲 `mushu` 即可启动（安装时已写入全局命令）。
- 桌面图标双击会先问「去哪个目录」，再启动。
- 设置：交互界面里敲 `/设置`（本期为 TUI 文本设置，GUI 面板未随包）。

## 本期包含 / 不包含（如实说明）
**包含：** 三模式 · 记忆与对话持久化 · 插件接口（可自装插件）· 全局命令 · Ollama 引擎 · 模型管理 · 长文档 · 信任门与工作区隔离 · 浏览器扩展 · PDF 读取 · 隐私协议页
**不包含：** Web 网页界面（依赖 flask）· 浏览器自动化 / 联网研究（依赖 playwright）· GUI 设置面板（走 TUI 兜底）· 浏览器桥看门狗（出厂关）· 线上模式需自配密钥
